# 메시지 토큰·시간 표시

실리태번 채팅 메시지의 원래 표시 위치에 다음 정보를 복구해서 보여주는 확장입니다.

- `123t`: 해당 메시지의 토큰 수
- `4.2s`: AI 답변 생성에 걸린 시간

## 작동 방식

- 별도의 배지나 새로운 표시 칸을 만들지 않습니다.
- 실리태번 기본 메시지 템플릿의 `.tokenCounterDisplay`와 `.mes_timer`를 그대로 사용합니다.
- 기본 표시 기능이 다시 정상 작동하더라도 같은 자리를 공유하므로 숫자가 중복되지 않습니다.
- 저장된 토큰 수가 없으면 실리태번이 현재 선택한 모델의 토크나이저로 다시 계산합니다.
- 기존 메시지에 생성 시작·완료 시간이 저장되어 있으면 과거 답변의 시간도 표시합니다.
- 생성 시간 정보가 원래 저장되지 않은 과거 메시지는 토큰 수만 표시됩니다.

## 시간 표시 수정

- 본답변이 `quiet`로 생성되는 경우에도 새로 표시된 답변의 시간을 측정합니다. 배경 생성 후 예전 답변을 다시 그렸다고 해서 가짜 시간을 붙이지 않습니다.
- 생성 완료 뒤 번역·검수 등으로 답변이 늦게 표시되어도 측정값을 1.5초 뒤에 지우지 않습니다.
- `MESSAGE_RECEIVED` 외에 실제 답변 렌더링과 화면 갱신에서도 시간 표시를 확인합니다.
- 실리태번이 같은 시간 칸의 글자를 다시 비우면 기록된 값으로 복구합니다.
- 스와이프별 기록을 구분하고, 채팅 전환 시 측정 상태를 초기화합니다.
- 저장된 생성 시작·완료 시각이 있으면 그 값을 우선합니다. 없는 새 답변은 확장이 관찰한 생성 이벤트의 시작·완료 시각으로 표시합니다. 이 보충 측정값은 현재 페이지에서만 유지되며 채팅 파일에는 쓰지 않습니다.
- 생성 요청·프롬프트·채팅 내용·다른 확장 설정은 수정하지 않습니다. 추가 API 호출도 하지 않습니다. 기존 메시지의 누락된 실제 생성 시간은 복원할 수 없습니다.

## 설치

1. ZIP 파일을 압축 해제합니다.
2. `message-metrics-display` 폴더를 아래 위치에 넣습니다.

   `SillyTavern/data/default-user/extensions/`

3. 실리태번을 완전히 새로고침합니다.
4. 확장 관리에서 **메시지 토큰·시간 표시**가 활성화되어 있는지 확인합니다.

사용자 계정 이름이 `default-user`가 아니라면 해당 사용자 폴더의 `extensions` 안에 넣으면 됩니다.

업데이트할 때는 기존 `message-metrics-display` 폴더 안에 ZIP의 파일 전체를 덮어쓰세요. 이번 버전은 새 `timing.js`도 필요합니다. 설치 후 새 답변 하나를 생성해 시간을 확인하세요.

## 제거

확장 관리에서 비활성화하거나 `message-metrics-display` 폴더를 삭제한 뒤 실리태번을 새로고침합니다.
